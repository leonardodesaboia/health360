# P0-13 — Longitudinal history and reassessment

Status: planned; **no implementation completed**.

## Why

Preserve events and prior plans while a new cycle is prepared.

## What Changes

profile/intake/analysis/review/publication events with provenance/version; new data enters REASSESSMENT_PENDING; reanalysis and review create a new plan; old plan remains identified as previous and readable; no predictive twin.

## Capabilities

### New Capabilities

- `reassessment`: Longitudinal history and reassessment.

### Modified Capabilities

None. This is a planned addition to the current foundation.

## Impact

health-timeline feature, profile versioning, plan history UI/service.

## Dependencies

P0-11, P0-12.

## Out of scope

Unrelated MVP modules, real-patient use, autonomous clinical decisions and product section 19 exclusions. This proposal does not authorize execution until assigned.
